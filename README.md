# 🍕 Sitio web de pizzería (GitHub Pages)

## Archivos
- `index.html`: página inteligente; detecta celular o computadora y redirige.
- `pc.html`: menú pensado para pantallas grandes.
- `movil.html`: menú optimizado para celulares.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `pizzeria-web`.
2. Sube estos tres archivos a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige `main` y `/ (root)`, luego **Save**.
6. Espera unos minutos. La URL será `https://TU-USUARIO.github.io/pizzeria-web/`.

## Código QR
Genera el QR usando la URL pública de `index.html` (la página inteligente), no la URL de `pc.html` ni `movil.html`. Así un solo QR funcionará para ambos dispositivos.
